# Data and supplementary tables

This repository accompanies the article

> Beyond accuracy: bias and error direction in machine learning surrogates for pushover assessment of RC frames.

The article compares modeling choices in machine learning surrogates of the pushover-based assessment of reinforced concrete frames: the representation of the capacity curve, the route to the target displacement, and the model of the performance level.

## Contents

| Item | Content |
|---|---|
| `data/frames.csv` | Database of 73,023 planar reinforced concrete frames: the 45 inputs, the capacity quantities, the target displacement and the performance level of every frame. |
| `data/normalized_curves.csv` | Normalized capacity curves of the 73,011 frames with a stored curve. |
| `data/predictions.csv` | Stored predictions of the models for every frame. |
| `data/README.md` | Description of every column of the three files, with units. |
| `Supplementary_tables.pdf` | Supplementary tables of the article (Tables S1 to S22), with a list of tables on the first page. |
| `LICENSE` | License of the files (CC BY 4.0). |

All data files are comma-separated (UTF-8) and are joined by `frame_id`. The performance levels IO, LS, CP and C are those of the Turkish Building Earthquake Code (TBEC 2018). In the files and tables, *actual* denotes a value obtained from the pushover analysis of a frame, and *predicted* a value returned by a surrogate model.

## Notes on the data

- The frames were generated by sampling and screened by code rules; they were not designed for the seismic actions of the site, so the shares of the performance levels do not describe a building stock.
- The second and third sampling waves were enriched in frames of the two most severe levels. Results that depend on the mix of levels should also be examined on the first wave (`sampling_wave` = 1).
- For about 15% of the frames, the ultimate displacement marks the end of the numerical solution and not a drop of the base shear to 80% of its peak (`curve_complete` = 0 among the frames with a stored curve).
- The numerical model represents flexural behavior with fiber sections. Shear failure, bar buckling, joint deformation and bond slip are not modeled.
